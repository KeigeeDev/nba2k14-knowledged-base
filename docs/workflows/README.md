## Notes for contributors

- Number the steps. Assume the reader has the tools listed in `docs/tools/` installed but hasn't done this specific task before.
- Note prerequisites (which tool version, which game patch/build) since NBA 2K14 mod compatibility can depend on this.
- Call out backup steps explicitly (e.g. "back up the original file before overwriting") — modding should not be able to silently corrupt a save or install.
