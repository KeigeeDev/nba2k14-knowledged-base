# Workflows

Task-oriented, step-by-step guides for specific mods — e.g. swapping a jersey texture, editing a roster, installing a court mod, importing a cyberface.

## Index

- [cyberface-blender.md](cyberface-blender.md): make or edit a cyberface: extract with the 3DM Tool, edit in Blender, re-import
- [roster-edit-csv.md](roster-edit-csv.md): bulk-edit a roster through RED MC's CSV export and import
- [ros-field-mapping.md](ros-field-mapping.md): find where an unknown field is stored in a `.ROS` file (differential editing)

## Notes for contributors

- Number the steps. Assume the reader has the tools listed in `docs/tools/` installed but hasn't done this specific task before.
- Note prerequisites (which tool version, which game patch/build) since NBA 2K14 mod compatibility can depend on this.
- Call out backup steps explicitly (e.g. "back up the original file before overwriting") — modding should not be able to silently corrupt a save or install.
