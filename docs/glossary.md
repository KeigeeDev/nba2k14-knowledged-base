# Glossary

Short definitions of terms and acronyms used across NBA 2K14 modding references. Keep alphabetized. Add a `[DRAFT]`/`[COMMUNITY]`/`[VERIFIED]` tag inline if a definition itself needs scrutiny.

- **Cyberface** — the in-game 3D face/head model+texture used to represent a specific player.
- **Court mod** — a mod that replaces textures/geometry for an in-game arena floor and surroundings.
- **Draft class** — a generated or custom set of incoming rookie players, stored in its own save file format.
- **MyTeam** — the card-collecting game mode; less commonly modded on PC for NBA 2K14 compared to franchise/roster content.
- **Roster file** — the save file holding player attributes, ratings, and team assignments, editable outside the game with the right tool.
