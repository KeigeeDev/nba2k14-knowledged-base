# Tools

One file per modding tool. Each file should cover: what the tool does, what platform/OS it runs on, where to get it (or that a source is still needed), install notes, and known issues.

## Index

- [3DM Tool](3dm-tool.md): opens `.iff` files; exports and imports cyberface models and textures
- [Cheat Engine](cheat-engine.md): live memory editing with `.CT` tables (MyCareer ratings, sliders)
- [Cyberface helper scripts](cyberface-scripts.md): `n2km_tools`, `dds_tools` and `cf_blender` (safety check, DDS read/write, Blender helpers)
- [io_n2km](io-n2km.md): Blender add-on to import and export `.n2km` models
- [MCP for Blender](mcp-for-blender.md): lets an AI assistant run Python in a live Blender session
- [RED MC](red-mc.md): roster editor; used to look up a player's CyberFace ID

## Notes for contributors

NBA 2K14's PC modding tool ecosystem has changed hands and gone through several unofficial forks over the years, and many original download links (old forum attachments, Mediafire/Mega links) are dead. When documenting a tool:

- Note the tool's **known aliases/forks** if any.
- Prefer linking to an active GitHub repo or archive over a single forum post.
- If you can't currently find a working download link, say so explicitly (`TODO: source needed`) rather than leaving a guessed URL.
