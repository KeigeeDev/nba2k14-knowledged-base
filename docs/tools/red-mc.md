# RED MC

**Status:** [COMMUNITY]
**Category:** tool
**Last updated:** 2026-09-27

## Summary

RED MC is a roster editor for NBA 2K13 and NBA 2K14 on PC. For cyberface work you use it to read or change a player's **CyberFace ID**, which tells you which `png<ID>.iff` file holds their head. You can also set appearance values such as eye colour there.

## Details

- **Cyberface use:** open the roster and go to the player's Appearance → CyberFace ID. ID 326 means the file `png0326.iff`.
- Eye colour is a roster setting (RED MC or Edit Player in game), not part of the face texture.
- According to search excerpts, changes are saved to the `.ROS` roster file, and RED MC comes with tutorials that explain its fields.
- An NLSC news post says RED MC and REDitor II were updated and all their features made free.
