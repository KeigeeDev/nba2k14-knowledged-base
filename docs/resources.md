# External Resources

Links to communities, forums, Discords, and archives relevant to NBA 2K14 modding. NBA 2K14's modding scene is old and scattered — many original hosting sites and forum threads have gone offline. Note a link's status (`live`, `archived`, `dead`) whenever known.

## Index

- [Hexorg/CheatEngineTables: NBA 2K14 table v2_179](https://github.com/Hexorg/CheatEngineTables/blob/master/tables/nba_2k14_cheat_table_v2_179.ct): `live` (as of 2026-09-24). Includes MyCareer ratings, clocks, and game speed. The repo has no license and the table's original author is unknown.

### Cyberfaces

Status note: the NLSC links below were found through web search on 2026-09-27 but couldn't be opened from the review environment (the forum is blocked there). Their status is `unchecked`, not `live`.

- [NLSC forum: NBA 2K14 Tutorials & FAQs](https://nba-live.com/forums/viewforum.php?f=154): `unchecked`. The main board for 2K14 modding tutorials.
- [icecr, "Tutorial: How to Create Any Cyber Face in Blender" (NLSC)](https://forums.nba-live.com/viewtopic.php?f=154&t=113460): `unchecked`. The base tutorial for the owner's [cyberface workflow](workflows/cyberface-blender.md).
- [NLSC: Universal Cyberface ID List](https://forums.nba-live.com/viewtopic.php?f=153&t=93692): `unchecked`. A list of CyberFace IDs, aimed at patch makers.
- [NLSC: Blender 2.8x–2.9x IO_N2KM](https://forums.nba-live.com/viewtopic.php?t=111897): `unchecked`. A port of the [io_n2km](tools/io-n2km.md) add-on.
- [NLSC: Tutorial: Importing 3D BEARD AND HAIR](https://forums.nba-live.com/viewtopic.php?f=154&t=96047): `unchecked`.
- [MCP for Blender on PyPI](https://pypi.org/project/mcp-for-blender/): `live` (as of 2026-09-27). See [tools/mcp-for-blender.md](tools/mcp-for-blender.md).

- If a link goes dead, don't delete the entry — mark it `dead` and, if possible, replace the URL with a Wayback Machine link so the knowledge isn't lost.
